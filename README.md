**FuryMC Launcher** is a specialized fork of **Zalith Launcher 2**, a modern Minecraft: Java Edition launcher for Android. 

### 🚀 Key Features of this Fork
*   **Offline Login:** Re-added the capability for unrestricted offline/local account play.
*   **Upstream Sync:** Actively maintained to stay synchronized with the latest updates from the official [Zalith Launcher 2](https://github.com/ZalithLauncher/ZalithLauncher2) project.
*   **Modern UI:** Inherits the beautiful Material Design 3 and Jetpack Compose interface from upstream.

## 📦 Build Instructions (For Developers)

As per the project's security protocol, **all builds are handled exclusively via GitHub Actions**. 

To build your own version:
1. Fork this repository.
2. Ensure you have the necessary secrets configured in your repository settings (e.g., `CURSEFORGE_API_KEY`).
3. Run the **Build CI** workflow.
